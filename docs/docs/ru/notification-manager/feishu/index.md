# Уведомления: Feishu / Lark

## Введение

Плагин **Feishu / Lark** позволяет приложению отправлять уведомления пользователям Feishu.

## Добавление и настройка аутентификатора Feishu

Сначала добавьте и настройте аутентификатор Feishu в NocoBase, см. [Аутентификация: Feishu / Lark](/auth-verification/auth-feishu/). Только пользователи, вошедшие через Feishu, могут получать системные уведомления через Feishu.

Сообщения отправляются через приложение Feishu выбранного аутентификатора, для которого дополнительно требуется:

1. Добавить возможность **Бот** в разделе **Возможности приложения** на открытой платформе — без неё отправка завершается ошибкой;
2. Включить право **Отправка сообщений от имени бота** (`im:message:send_as_bot`) в разделе **Права** и опубликовать новую версию;
3. Получатели должны входить в **область прав на контакты** приложения (область доступности).

После изменения возможностей или прав опубликуйте новую версию и повторите отправку.

## Добавление канала уведомлений Feishu

Перейдите в **Управление уведомлениями** → каналы, добавьте канал **Feishu / Lark** и выберите настроенный аутентификатор.

Дополнительно можно настроить **тип ID получателя** (`open_id`, `user_id`, `union_id` или `email`); по умолчанию используется поле уникального идентификатора аутентификатора.

## Типы сообщений

| Тип | Описание |
| --- | --- |
| Текстовое сообщение | Простой текст. |
| Сообщение Post | Форматированный текст в формате Feishu Post. |
| Интерактивная карточка | Карточка Feishu, настраиваемая через JSON. |

Получатели определяются по идентификатору Feishu, связанному с аутентификатором (по типу ID получателя); для несвязанных пользователей используется email или имя пользователя.

## Узел уведомлений в workflow

Выберите настроенный канал Feishu в узле уведомлений workflow, чтобы отправлять сообщения Feishu пользователям из контекста workflow.

## Устранение неполадок

- Отправка завершается ошибкой прав (например, код `230002`): проверьте, что добавлена возможность **Бот** и включено право **Отправка сообщений от имени бота**, а последняя версия приложения опубликована.
- Ошибка недопустимого получателя (`receive_id`): получатель вне области прав на контакты приложения либо тип ID получателя не соответствует настройке канала.
- Задача завершается общей ошибкой: найдите запись `FeishuNotificationChannel.send failed` в журналах сервера; новые версии плагина также выводят код и сообщение ошибки Feishu.
