# Движок хранения: локальное хранилище

Загруженные файлы будут сохранены в локальном каталоге на жёстком диске сервера. Это подходит для сценариев с небольшим суммарным объёмом загруженных файлов, которыми управляет система, или для экспериментальных целей.


:::warning Примечание

По возможности используйте для локальных файлов стабильные URL `/files/`, чтобы NocoBase мог проверить запись файла и разрешение текущей роли на просмотр. Устаревшие URL `/storage/uploads/` не применяют разрешения на уровне записи, но Docker, встроенный Nginx и конфигурации Nginx, созданные NocoBase CLI, по умолчанию ограничивают их авторизованными пользователями.

Если нужно хранить договоры, документы, внутренние материалы или другие непубличные файлы, используйте [S3 Pro](./s3-pro). Если исторические файлы уже есть, см. [Миграция на S3 Pro](./migrate-to-s3-pro.md).

Если собственный Nginx отдаёт локальные загрузки через `alias`, его location `/storage/uploads/` должен использовать `auth_request` для вызова endpoint аутентификации NocoBase. Иначе стандартная проверка входа будет обойдена. Также задайте `X-Content-Type-Options: nosniff` и возвращайте файлы с активным содержимым, такие как `html`, `svg`, `xhtml` и `pdf`, как вложения. Полный пример и настройку подприложений см. в разделе [Обратный прокси Nginx](../../nocobase-cli/production/reverse-proxy/nginx.md), а риски — в [руководстве по безопасности: хранение файлов](../../security/guide.md#хранение-файлов).

Если существующая интеграция зависит от анонимного доступа к устаревшим URL, задайте `LEGACY_LOCAL_STORAGE_PUBLIC_ACCESS=true` и перезапустите приложение. Этот переключатель совместимости влияет только на `/storage/uploads/` и не изменяет разрешения на уровне записи для `/files/`.

### Путь

Задаёт одновременно относительный путь хранения файлов на сервере и URL-путь доступа. Например, "`user/avatar`" (без начальных и конечных слэшей) означает:

1. Относительный путь на сервере, где хранятся загруженные файлы: `/path/to/nocobase-app/storage/uploads/user/avatar`.
2. URL-префикс для доступа к файлам: `http://localhost:13000/storage/uploads/user/avatar`.
