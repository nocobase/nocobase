# RAG-поиск

## Введение

В NocoBase **RAG (генерация с дополнением извлечёнными данными)** позволяет ИИ-сотруднику получать релевантные материалы из баз знаний перед ответом на вопрос.

Базы знаний, которые ИИ-сотрудник может использовать, определяются одновременно его настройкой `Knowledge Base` и правами ролей текущего пользователя на базы знаний. Поиск выполняется только в базах, входящих в оба набора.

## Настройка баз знаний ИИ-сотрудника

Откройте страницу настроек `AI employees`, выберите ИИ-сотрудника, для которого нужно включить RAG, и нажмите `Edit`. В панели редактирования откройте вкладку `Knowledge Base` и включите `Enable`.

![](https://static-docs.nocobase.com/ai-employee-knowledge-base-settings-202608171620.png)

Доступны следующие настройки:

- `Knowledge Base` — Необязательное поле. Если оставить его пустым, ИИ-сотрудник будет искать во всех включённых базах знаний, доступных ролям текущего пользователя. Если выбрать базы знаний, поиск будет выполняться только в выбранных базах, к которым у пользователя есть доступ
- `Retrieval strategy` — Определяет, когда выполняется поиск по базам знаний:
  - `Retrieve on demand` — ИИ-сотрудник извлекает материалы, только когда определяет, что они нужны для текущего вопроса. Эта стратегия используется по умолчанию для новых ИИ-сотрудников и рекомендуется для большинства случаев
  - `Automatically retrieve for every question` — Поиск выполняется перед отправкой каждого вопроса пользователя ИИ-сотруднику. Используйте эту стратегию, если каждое сообщение требует материалов из базы знаний
- `Knowledge Base Prompt` — Определяет, как извлечённые материалы передаются ИИ-сотруднику. `{knowledgeBaseData}` — фиксированный плейсхолдер; не удаляйте и не изменяйте его
- `Top K` — Максимальное количество результатов для каждого поиска. Допустимый диапазон — от 1 до 100, значение по умолчанию — 3
- `Score` — Минимальная оценка сходства, необходимая для включения результата. Допустимый диапазон — от 0 до 1, значение по умолчанию — 0,6. Более высокое значение повышает релевантность материалов, но может уменьшить количество результатов

Нажмите `Submit`, чтобы сохранить настройки.

## Настройка прав на базы знаний

Выбор баз знаний для ИИ-сотрудника не предоставляет к ним доступ всем пользователям. Откройте `Users & Permissions / Roles & Permissions`, выберите роль, назначенную пользователю, а затем откройте `Permissions / Knowledge bases`.

Выберите `Available` для каждой базы знаний, к которой роль должна иметь доступ. Чтобы автоматически предоставлять этой роли доступ к базам знаний, созданным в будущем, выберите `New knowledge bases are allowed by default`.

![](https://static-docs.nocobase.com/knowledge-base-role-permissions-202608171620.png)

:::warning Примечание

Доступный ИИ-сотруднику набор баз знаний представляет собой пересечение его настройки `Knowledge Base` и прав ролей текущего пользователя. Базы знаний без соответствующего разрешения автоматически исключаются.

:::

## Если у пользователя нет доступа к базам знаний

Если базы знаний включены для ИИ-сотрудника, но настроенный набор не пересекается с правами ролей текущего пользователя, ИИ-сотрудник сначала отвечает, используя информацию, не зависящую от базы знаний. Затем он добавляет заметное уведомление о том, что материалы из баз знаний не использовались из-за отсутствия доступа, и рекомендует обратиться к администратору.

![](https://static-docs.nocobase.com/ai-employee-no-knowledge-base-access-side-panel-202608171653.png)

Если пользователю доступна хотя бы одна база знаний, но для текущего вопроса не найдено релевантных материалов, уведомление об отсутствии прав не отображается.
