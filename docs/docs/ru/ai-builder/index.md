# Быстрый старт Мастера ИИ-разработки

Мастер ИИ-разработки — возможность NocoBase для создания с помощью ИИ: вы описываете бизнес-требования на естественном языке, а ИИ агент собирает систему за вас. Это покрывает всю цепочку — от моделирования данных, создания интерфейса, оркестрации рабочих процессов и настройки прав доступа до выхода в продакшен.

Если говорить конкретно о том, **как создаётся интерфейс**, есть два способа:

- **ИИ + разработка в Portal без кода** — ИИ строит интерфейс системы, опираясь на возможности конфигурации без кода в NocoBase; результат — конфигурация, сохранённая в базе данных. Подходит для стандартных операций с данными и внутренних административных панелей, а бизнес-пользователи затем могут дорабатывать интерфейс сами
- **Разработка в AI Portal** — NocoBase предоставляет базовые возможности (данные, аутентификация, права доступа и другое), а ИИ агент пишет код прямо локально, и результат можно сразу коммитить в Git. После сборки и развёртывания страницы доступны через [AI Portal](./ai-portal/index.md). Подходит для нестандартных взаимодействий, сложных бизнес-систем и случаев с особыми требованиями к оформлению

Какой бы способ вы ни выбрали, таблицы данных, права доступа и рабочие процессы используют один и тот же набор Навыков: пока ИИ агент пишет страницы, он заодно создаст таблицы данных и настроит права доступа — так в диалоге постепенно собирается полноценная бизнес-система.

## Как выбрать способ разработки

Каждому из этих двух способов соответствует своя точка входа. У одного приложения NocoBase может быть несколько точек входа с общими данными, и по пути доступа сразу видно, какая перед вами:

```text
/v/<name>    Portal без кода
/x/<name>    AI Portal
```

![two types of portal](https://static-docs.nocobase.com/20260804091849.png)

Различия:

| | Portal без кода | AI Portal |
| --- | --- | --- |
| Путь доступа | `/v/<name>` | `/x/<name>` |
| Откуда берутся страницы | Настраиваются в интерфейсе, ИИ может помочь изменить конфигурацию | Исходный код на React, который пишет ИИ агент |
| Результат | Конфигурация, сохранённая в базе данных | Исходный код, который можно коммитить в Git |
| Как идёт итерация | Клики в интерфейсе или изменение конфигурации силами ИИ | Правка кода, `dev` → `deploy` |
| Управление версиями | Снимки через [контроль версий](./version-control.md) | Git или NocoBase source storage |
| Свобода интерфейса | Ограничена возможностями блоков, макет и взаимодействие следуют заданным шаблонам | Каким захотите, таким и будет |
| Готовые возможности | Панели, календарь, канбан и другие блоки работают сразу | Наш стандартный шаблон кода или собственная реализация ИИ агента |
| Порог входа | Нужно разбираться в блоках, полях и других понятиях NocoBase | Нужен некоторый опыт работы с ИИ агентами |
| Подходит для | Стандартные операции с данными, внутренние административные панели | Нестандартные взаимодействия, сложные бизнес-системы, особые требования к оформлению |

В этих случаях Portal без кода вполне достаточно:

- Структура страниц совершенно стандартная — обычная таблица плюс форма, и настроить её быстрее, чем написать код
- Нужно, чтобы бизнес-пользователи без навыков программирования сами правили страницы
- Вы хотите использовать только встроенные возможности блоков NocoBase — например, панели, календарь или канбан
- Вы работаете в одиночку или совместная разработка не требуется

В остальных случаях мы рекомендуем разработку через [AI Portal](./ai-portal/index.md). При разработке в Portal без кода ИИ приходится усваивать слишком много контекста — типы блоков, структуру конфигурации, правила интерактивных связок, — и для бизнес-систем, требующих сложной разработки, это плохо сказывается на скорости, сопровождаемости и совместной работе.

Поэтому мы подошли к задаче иначе: **писать фронтенд-код — это то, что ИИ умеет лучше всего**, так пусть он и занимается тем, что у него получается лучше всего. NocoBase выступает базой системного ядра, а фронтенд отдаётся ИИ. При тех же требованиях получается и быстрее, и лучше. **ИИ творит свободно, а за надёжность отвечает NocoBase.**

Оба режима можно и совмещать: внутреннюю административную панель быстро настроить в Portal без кода, а клиентский портал тонко доработать в AI Portal — оба находятся в одном приложении и используют общие данные и общую систему пользователей.

## Быстрый старт

::: warning Примечание
Если вы хотите попробовать разработку в AI Portal, установите alpha-версию NocoBase CLI (`npm install -g @nocobase/cli@alpha`).
:::

Если вы уже установили [NocoBase CLI](../ai/quick-start.md), этот шаг можно пропустить.

### Установка в один клик с помощью ИИ

Скопируйте приведённый ниже запрос в ваш ИИ-ассистент (Claude Code, Codex, Cursor, Trae и т. д.) — он автоматически выполнит установку и настройку:

```
Помоги мне установить NocoBase CLI и завершить инициализацию: https://docs.nocobase.com/ai/ai-quick-start.md (пожалуйста, прочитай содержимое по ссылке напрямую)
```

### Ручная установка

```bash
npm install -g @nocobase/cli@alpha
nb init --ui
```

Браузер автоматически откроет страницу визуальной настройки и проведёт вас через установку NocoBase Skills, настройку базы данных и запуск приложения. Подробные шаги см. в [Быстрый старт](../ai/quick-start.md).

## Замените ручную настройку диалогом

После установки вы можете управлять NocoBase прямо из ИИ-ассистента на естественном языке. Ниже — несколько реальных сценариев: от создания одной таблицы до построения целой системы, чтобы вы могли оценить возможности Мастера ИИ-разработки.

### Опишите бизнес-требования — ИИ спроектирует таблицы и связи

Расскажите ИИ, какую систему вы хотите построить — он автоматически спроектирует таблицы данных, типы полей и связи; рисовать ER-диаграммы самому не нужно.

```
Я создаю CRM, помоги спроектировать и построить модель данных
```

![ИИ проектирует модель данных CRM](https://static-docs.nocobase.com/202604162126729.png)

ИИ автоматически сгенерировал таблицы данных для клиентов, контактов, сделок, заказов и их связи:

![Результат модели данных CRM](https://static-docs.nocobase.com/202604162201867.png)

Подробнее о моделировании данных см. [Моделирование данных](./data-modeling).

### Создайте веху — и ИИ сохранит восстанавливаемую версию

После завершения страницы, набора таблиц данных или рабочего процесса попросите ИИ сохранить текущее состояние как версию — если конфигурация пойдёт не так, всегда можно откатиться к последней понятной вехе.

```
Сохрани текущую сборку как версию: завершена страница управления клиентами, область фильтров и конфигурация формы редактирования
```

![ИИ создаёт версию после построения](https://static-docs.nocobase.com/20260611115804.png)

ИИ не сохраняет версию при каждом изменении поля; версия создаётся только после завершения и проверки понятной вехи — так список версий остаётся читаемым, и проще решить, куда откатываться.

Подробнее о контроле версий см. [Контроль версий](./version-control).

### Оркестрируйте автоматизированные рабочие процессы одной фразой

Опишите условия срабатывания и логику обработки бизнес-процесса — ИИ автоматически создаст триггеры и цепочки узлов.

```
Помоги настроить рабочий процесс, который автоматически списывает товар со склада после создания заказа
```

![Рабочий процесс списания товара по заказу](https://static-docs.nocobase.com/20260419234303.png)

Подробнее о рабочих процессах см. [Управление рабочими процессами](./workflow).

### Опишите страницы на языке бизнеса — ИИ их создаст

NocoBase по умолчанию предоставляет один **AI Portal** и один **Portal без кода**. Не нужно изучать правила конфигурации — просто скажите, какая страница вам нужна. Поля поиска, таблицы, фильтры — опишите, и готово.

![portal manage](https://static-docs.nocobase.com/20260804104517.png)

Если вы создаёте страницу в Portal без кода (Portal по умолчанию называется admin), запрос выглядит так:

```
Помоги создать в admin страницу управления клиентами с полем поиска по имени и таблицей клиентов с колонками: имя, телефон, email и время создания
```

![Страница управления клиентами](https://static-docs.nocobase.com/20260420100608.png)

Если вы создаёте страницу в режиме AI Portal (Portal по умолчанию называется main), запрос выглядит так:

```
Помоги создать в main portal страницу управления клиентами с полем поиска и таблицей клиентов с колонками: имя, телефон, отрасль
```

![portal страница](https://static-docs.nocobase.com/20260803204422.png)

Подробнее о настройке интерфейса см. [Настройка интерфейса](./ui-builder) или [Разработка в AI Portal](./ai-portal/index.md).

## Безопасность и аудит

Перед тем как позволить ИИ агенту управлять NocoBase, рекомендуем разобраться со способами аутентификации, контролем прав доступа и аудитом операций — чтобы ИИ делал только то, что нужно, а каждый шаг был зафиксирован. См. [Безопасность и аудит](./security).

## NocoBase Skills

[NocoBase Skills](https://github.com/nocobase/skills) — пакеты предметных знаний, устанавливаемые в ИИ агенты, которые позволяют ИИ понимать систему конфигурации NocoBase. NocoBase предоставляет несколько Навыков, охватывающих весь процесс разработки:

- [Управление окружением](./env-bootstrap) — проверка окружения, установка, развёртывание, обновление и устранение неполадок
- [Моделирование данных](./data-modeling) — создание и управление таблицами данных, полями и связями
- [Настройка интерфейса](./ui-builder) — создание и редактирование страниц, блоков, всплывающих окон и интерактивных связок
- [Управление рабочими процессами](./workflow) — создание, редактирование, включение и диагностика рабочих процессов
- [Настройка ACL](./acl) — управление ролями, политиками прав доступа, привязкой пользователей и оценкой рисков
- [Решения](./dsl-reconciler) — пакетное построение целых бизнес-систем из YAML
- [Управление плагинами](./plugin-manage) — просмотр, включение и отключение плагинов
- [Управление релизами](./publish) — кросс-окружное развёртывание, резервное копирование и восстановление, миграция
- [Контроль версий](./version-control) — сохранение восстанавливаемых версий после завершённых вех
- [Разработка в AI Portal](https://github.com/nocobase/skills/blob/main/skills/nocobase-ai-builder/SKILL.md) - позволяет ИИ агенту писать код в AI Portal и строить интерфейс системы

:::tip

NocoBase CLI автоматически устанавливает Skills при инициализации (`nb init`), поэтому ручная установка не требуется.

:::
