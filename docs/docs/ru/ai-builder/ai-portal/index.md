# Быстрый старт AI Portal

Мы заметили, что ИИ в режиме vibe coding вполне способен выдать красивую страницу, но с трудом стыкует её с реальной бизнес-системой — либо начинает с нуля реализовывать аутентификацию, права доступа и структуру таблиц данных.

NocoBase как low-code/no-code платформа всё это уже предоставляет. Вы можете считать её базой системного ядра: ИИ агент сосредотачивается на бизнес-логике, а NocoBase отвечает за надёжную инфраструктуру — аутентификацию, базу данных, API и права доступа.

Для этого мы предоставляем точку входа приложения под названием **AI Portal**. Её исходный код лежит локально и предназначен именно для того, чтобы его писал ИИ агент. Код, написанный в этой точке входа, обращается к встроенным возможностям NocoBase напрямую, а собранные страницы сразу доступны для просмотра.

![AI Portal Settings](https://static-docs.nocobase.com/20260803154352.png)

## Что предоставляет NocoBase

Когда вы строите бизнес-систему, время обычно уходит не на страницы, а на то, что за ними стоит: вход пользователей, проверку прав, проектирование таблиц данных, API для операций с данными, загрузку и скачивание файлов. Всё это нужно каждой системе, и делать это заново каждый раз невыгодно.

В NocoBase всё это уже есть:

- **Аутентификация** — вход по логину и паролю работает сразу. OIDC, SAML, CAS, LDAP, SMS, DingTalk, WeCom и другие способы работают после включения на сервере, фронтенду остаётся только подключиться к ним
- **База данных и несколько источников данных** — встроенное управление таблицами данных плюс подключение внешних источников, таких как MySQL и PostgreSQL
- **REST API** — как только появляется таблица данных, вместе с ней появляются и эндпоинты для операций с данными, с поддержкой фильтрации, сортировки, постраничного вывода и полей связей
- **Контроль доступа** — ACL на основе ролей вплоть до уровня полей и записей. Фронтенд может прочитать права текущего пользователя и решить, что показывать
- **Рабочие процессы** — автоматизация бизнес-процессов, запускаемая с фронтенда или изменением данных
- **Файловое хранилище** — загрузка и скачивание

![AI Portal Template](https://static-docs.nocobase.com/20260803161414.png)

На основе этих возможностей мы построили стандартный [шаблон системы](https://github.com/nocobase/portal-template-default), который ИИ агент может просто скопировать и получить работающее приложение. Кроме того, NocoBase предоставляет набор Навыков — [моделирование данных](../data-modeling.md), [настройка ACL](../acl.md) и другие, — так что после описания бизнес-требований ИИ агент не только сгенерирует фронтенд-страницы, но и создаст таблицы данных и настроит права доступа, собрав полноценную бизнес-систему.

## Предварительные требования

- NocoBase >= 3.0.0-alpha.6
- Node.js >= 22
- [pnpm](https://pnpm.io/installation) — шаблон Portal использует его для установки зависимостей и запуска сервера разработки
- Alpha-версия `nocobase cli` (**внимание: пока поддерживается только alpha-версия**)
  - `npm install -g @nocobase/cli@alpha`
  - А также приложение NocoBase, уже инициализированное через `nb init --ui`, см. [Руководство по интеграции ИИ агентов](../../ai/quick-start.md)
- ИИ агент, например Claude Code, Codex или Cursor

## Шаг 1: убедитесь, что у вас уже есть AI Portal

Сначала проверьте, что `main` по умолчанию действительно на месте:

```bash
nb portal list
```

![nb portal list](https://static-docs.nocobase.com/20260803163517.png)

В выводе перечислены имя Portal, URL доступа, тип Portal, source storage, путь разработки, состояние включения и признак Portal по умолчанию.

После загрузки исходного кода команда `info` покажет больше подробностей — например, куда указывают путь разработки и путь развёртывания:

```bash
nb portal info main
```

## Шаг 2: запустите режим разработки

```bash
# Загрузить исходный код portal
nb portal pull main
# Запустить сервер разработки
nb portal dev main
```

Сервер разработки по умолчанию работает на `http://localhost:5173`.

В шаблоне есть готовая страница управления пользователями, построенная на таблице данных `users` из NocoBase. Войдите и посмотрите на неё — заодно это хороший начальный пример, на который может ориентироваться ИИ.

![portal dev home page](https://static-docs.nocobase.com/20260802220652.png)

## Шаг 3: попросите ИИ изменить страницу

Перейдите в рабочее пространство разработки Portal (`pull` по умолчанию кладёт его в `./main`; если не уверены, посмотрите путь разработки через `nb portal info main`), откройте там свой ИИ агент — Claude Code, Codex, Cursor, любой — и дайте ему запрос:

```
Добавь страницу управления клиентами
со списком клиентов, поиском по имени и выдвижной панелью с деталями, которая открывается по клику на строку
```

<!-- 需要一个视频，展示从输入提示词到 AI 完成页面编写、开发服务热更新出效果的完整过程 -->

ИИ прочитает существующие страницы и расширения, напишет новую страницу по соглашениям шаблона, и результат вы увидите на `http://localhost:5173`.

О том, как эффективно работать с ИИ агентом, см. [Совместная разработка с ИИ агентом](./agent-workflow.md).

## Шаг 4: развёртывание

Когда локальные изменения выглядят как надо, отправьте исходный код на удалённую сторону, затем соберите и разверните:

```bash
nb portal push main --message "Add customer management page"
nb portal deploy main
```

Куда именно `push` отправит исходный код, зависит от настройки source storage этого Portal. По умолчанию это `nocobase`, и исходным кодом управляет NocoBase. Если через [`nb portal config`](../../api/cli/portal/config.md) выбрать `git`, то `push` закоммитит и отправит исходный код в указанный вами репозиторий Git, а `--message` станет сообщением коммита Git. Подробнее см. [Развёртывание и управление исходным кодом](./deploy.md#source-storage).

После развёртывания откройте `/x/main/` — и увидите свои изменения.

На этом полный цикл замкнулся: вы описываете требования, ИИ пишет код, вы смотрите результат локально, затем отправляете и разворачиваете.

## Когда нужно больше точек входа

У приложения может быть несколько Portal. Внутренние сотрудники пользуются одним, внешние клиенты — другим: страницы и права доступа полностью раздельные, а данные общие:

```bash
nb portal create customer
```

При создании в текущем каталоге появится `./customer` как рабочее пространство разработки; можно указать другое место через `--path`. Новый Portal разрабатывается через `nb portal dev` и разворачивается через `nb portal deploy` точно так же, как первый — зайдите в его рабочее пространство и откройте свой ИИ агент. Подробнее см. [Развёртывание и управление исходным кодом](./deploy.md).

## Демо

Если хотите посмотреть на разработку в AI Portal в деле, запросите демо-окружение: https://demo.nocobase.com/new. После заполнения формы мы сгенерируем для вас отдельное демо-окружение с несколькими приложениями AI Portal, построенными на базе NocoBase.

![AI Portal Settings](https://static-docs.nocobase.com/20260803154352.png)

Затем выберите AI Portal и зайдите в него:

![AI Portal CRM](https://static-docs.nocobase.com/20260803154700.png)

На приветственной странице Portal мы также даём запрос, с помощью которого ваш ИИ агент подключится к этому приложению AI Portal напрямую, загрузит код приложения, запустит сервер разработки локально, изменит страницы, а потом отправит и развернёт всё обратно в демо-окружение. Обновите страницу после успешного развёртывания — и увидите результат.
