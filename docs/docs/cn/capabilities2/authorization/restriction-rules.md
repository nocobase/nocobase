# 限制规则

限制规则在已有授权上收窄记录范围，让岗位、共同范围和共享都遵守同一业务边界。它不授予原本没有的操作或数据访问权。

## 示例：额外费用协作范围

```text
Northstar 的费用协作岗位只负责额外费用不超过 2,000 元的申请。
为该岗位适用人员的「查看额外费用申请」操作增加限制规则，允许金额小于或等于 2,000 元的记录。
限制同时作用于岗位范围、默认范围和共享获得的查看范围。
在「团队访问」中提供这条业务条件的管理入口。
不要把限制条件当作授权，也不要给没有查看权限的人自动开放申请。
```

最终能查看的是员工原本有权访问、并且符合金额条件的申请。金额恰好为 2,000 元属于本例允许范围；其他人共享一笔更高金额的申请，也不能突破这个限制。

## 每项操作分别说明

本例限制查看操作。若编辑或审批同样需要金额上限，应分别声明并接入相应规则，而不是认为一个查看条件自动覆盖所有动作。

限制与已有授权取交集，多项限制需要同时满足。管理员填写的是允许访问的条件；例如「非敏感」表示只保留非敏感记录。

复杂关联条件与跨操作的业务边界需要应用进一步接入。用[权限检查](./inspector.md)查看限制来源，再结合实际员工账号查看业务效果。
