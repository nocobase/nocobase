# 认证

认证用于确认访问应用的人员身份。员工登录后，应用通过会话识别当前用户；可以查看哪些数据、执行哪些业务操作，由[权限](../authorization/index.md)进一步决定。

## 提供哪些能力

| 能力                                     | 可以做什么                                                           |
| ---------------------------------------- | -------------------------------------------------------------------- |
| [密码认证与账号](./password.md)          | 使用用户名或邮箱和密码登录，管理注册、密码要求、找回密码和登录状态。 |
| [账号与会话管理](./password.md#员工账号由公司管理)                           | 创建或停用员工账号、退出登录，以及撤销已有会话。                     |
| [API keys](./api-keys.md)                | 为脚本和外部集成提供认证凭据，设置有效期并按需撤销。                 |
| [增加认证方式](./sign-in-methods.md)     | 接入企业身份平台、第三方账号或其他认证方式。                         |
| [定制登录页面](./login-pages.md)         | 调整名称、标识、背景、布局和登录入口，适配企业品牌。                 |
| [保护页面和接口](./protecting-access.md) | 区分公开页面与需要登录的业务，并在接口中识别当前用户。               |

## 登录页面

应用提供用户名或邮箱和密码登录。本例使用蓝色风格的 Northstar 登录页面，包含账号、密码输入框、**Sign in** 按钮和找回密码入口；允许自助注册时，也可以显示 **Sign up** 入口。

![Northstar 蓝色登录页面](../assets/northstar-password-login-en.png)

注册是否开放、找回密码是否能发送邮件，以及其他登录方式，取决于应用的认证配置和已接入的服务。

## 定制自己的登录页面

基础登录可用后，可以让 Agent 按企业品牌调整页面。例如，Northstar Logistics 可以使用自己的名称、标识和运输背景，让员工从公司的登录页进入业务系统。

页面外观可以变化，登录表单仍复用认证能力。接下来查看[定制登录页面](./login-pages.md)，了解如何用提示词完成定制，并查看 Northstar 的页面效果。
