# 依据知识回答问题

企业业务规则往往保存在文档中。AI 员工可以在允许访问的资料中查找相关内容，结合问题整理回答，并提供来源，帮助用户理解依据和继续查阅原文。

## 示例：查询运输异常处理规范

```text
让 Northstar 的运输助理使用运输规范知识空间。
员工询问处理规则时，先检索相关内容，再据此整理回答；显示引用文档和段落入口。
没有找到依据时明确说明，不自行编造企业规定。
在知识中心阅读资料时也能打开对话，原文和回答同时可见。
沿用当前用户与助手允许的资料范围，不暴露财务等受限内容。
```

## 查看效果

在知识中心打开 **Temperature-controlled transport（温控运输规范）**，询问：

```text
如果货物温度超出约定范围，司机应该怎么处理？
```

左侧展示规范原文，右侧回答整理记录时间与温度、检查设备、通知调度员以及按客户要求处理等步骤。来源卡片连接原文中的 **Handling temperature deviations（温度异常处理）** 段落。

![温控运输规范原文、运输助理回答和资料来源](../assets/northstar-ai-knowledge-answer-en.png)

**回答与企业资料连接，用户可以查看来源，核对适用的处理要求。**

:::tip 重要提示

知识资料和业务数据承担不同职责：规范说明如何处理，订单查询提供当前事实。资料会更新，应维护有效内容与访问范围；文档里的处理建议不会自动变成已执行的业务操作。

:::
