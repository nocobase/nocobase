# 查阅与搜索

员工可以从知识目录打开文章或文件，阅读业务规范的原文，也可以输入关键词查找相关资料。搜索结果提供文档标题、段落和内容摘录，帮助用户判断是否相关，再回到原文核对上下文。

应用接入语义检索后，还可以用自然语言描述问题，按含义查找相关段落，而无需知道资料里的准确用词。

## 示例：查找温度异常处理要求

Northstar 的司机遇到货物温度异常，需要找到处理要求并核对原文。已知术语时可以搜索“温度异常”；不确定资料用词时，希望直接询问“货物温度异常时司机应如何处理？”。

把需求交给 Agent：

```text
为 Northstar 的知识中心提供资料阅读与搜索入口。
员工可以搜索“温度异常”，看到相关文档、段落和摘录，并打开原文。
同时接入语义检索，让员工输入“货物温度异常时司机应如何处理？”
也能查到温控运输规范中的“温度异常处理”段落。
结果显示资料来源，点击后查看原文；保留当前用户可阅读的资料范围。
请先确认所需模型和索引可用，不把关键词搜索当成已开通的语义检索。
```

![自然语言搜索结果、资料来源与温度异常处理原文](../assets/northstar-knowledge-search-en.png)

**接入语义检索后，自然语言问题可以找到相关规范；文档、段落和原文同时提供依据，便于员工核对处理要求。**

:::tip 重要提示

关键词查找可以直接使用。语义检索需要应用接入相应模型与资料索引，并在索引可用后才能按含义检索。找到相关资料不等于 AI 已整理答案；需要基于资料回答问题时，继续阅读[依据知识回答问题](./answers.md)。

:::
