# AI 知识库概览

知识库把文章、文件和业务说明组织成可维护、可搜索的企业资料。员工可以直接查阅资料，也可以让 AI 员工在允许的知识范围中检索，为业务问题提供有依据的回答。

## 提供哪些能力

| 能力 | 可以解决什么问题 |
| --- | --- |
| [组织与导入资料](./organize.md) | 按空间、文件夹、文章和文件整理不同用途的内容。 |
| [查阅与搜索](./search.md) | 阅读原文，从资料中查找相关内容；按需求接入语义检索。 |
| [为 AI 员工提供知识](./answers.md) | 在回答中使用企业资料，并连接相关来源。 |
| [访问与协作](./access.md) | 分配阅读、提出修改、编辑和管理权限。 |
| [版本与处理状态](./maintenance.md) | 保留内容更新与版本，查看文件解析和索引处理状态。 |

知识中心的入口和布局可以由应用按业务需要构建。文档权限、历史和修改入口放在对应资料旁边，员工无需先进入统一设置页。

## 在业务中使用知识

Northstar 的运输资料包括签收要求、温控异常处理和客户服务说明。运营人员维护规范，调度员查阅；运输助理使用相关资料回答处理问题，并提供来源入口。

```text
为 Northstar 运输应用接入知识中心，整理运输规范、客户服务说明和司机手册。
提供文件夹、文章和文件的阅读与搜索入口，按岗位控制访问范围。
让运输助理使用运输规范回答业务问题，返回相关文档和段落入口。
模型服务、检索方式和索引由应用接入，员工页面保留清晰的资料来源。
```

先看[依据知识回答问题](./answers.md)，了解如何把资料、回答和原文连接起来。基础资料维护与查阅可以独立使用；AI 回答需要可用模型，语义检索还需接入相应模型与索引。
