# 版本与处理状态

文章和文件的更新保留版本历史，便于查看过去的内容与比较变化。文件上传后的文本解析，与语义检索所需的索引处理，是不同的阶段：解析完成说明已经提取文件文本，索引状态说明当前文档的段落是否完成处理。

## 示例：更新温控运输规范

Northstar 的运营编辑为温控运输规范补充异常记录要求。运营管理员需要比较更新前后的版本，并查看文件解析和语义索引进度，发现尚未完成索引的资料。

```text
在 Northstar 知识中心展示温控运输规范的版本历史和版本比较。
在接入语义检索的运输规范空间，分别显示文件解析状态、段落索引进度和未完成索引的资料。
索引失败时显示原因并提供重新索引入口，不把单个文件解析完成显示为全库已经可检索。
```

## 查看效果

打开 **温控运输规范.docx** 的版本历史，比较 v2 与当前 v3，可见新增的异常时间、温度和处理经过记录要求。当前版本的文件解析已完成，但语义索引只有 **2/3 段**完成，仍有一段等待处理；未完成索引列表还展示 **延误报告.md** 的失败段落及重新索引入口。

![温控运输规范的版本历史、文件解析状态与未完成索引](../assets/northstar-knowledge-maintenance.png)

**内容变化可以追溯，解析与索引进度分别可见，维护者能继续处理尚未完成的资料。**

:::tip 重要提示

语义索引状态在应用接入相应检索能力后提供。一个文件解析完成或一份文档索引完成，都不能代表全部知识资料已可用于回答；回答仍需检索到适用内容并遵守访问权限。版本历史也不意味着外部资料会自动同步。

:::
