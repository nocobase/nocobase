# 组织与导入资料

知识库可以按空间区分资料用途，在空间内用文件夹整理文章与文件。文章适合持续维护业务说明，文件适合导入已有资料；上传后的文件可以查看原件预览与解析文本，便于后续阅读和搜索。

## 示例：整理运输规范与司机手册

Northstar 的运营人员需要维护温控运输、交付确认等规范，也需要把已有的出车检查清单提供给司机。将运输规范和司机手册分别整理，员工就能按用途找到资料。

把需求交给 Agent：

```text
为 Northstar 的知识中心整理两个知识空间：运输规范、司机手册。
在运输规范中创建“温控运输”文件夹，编写“温控运输规范”和“交付确认”文章。
温控运输规范包含出发前、温度异常处理、交付凭证三个段落。
在司机手册中创建“出车准备”文件夹，提供文件上传入口；
我会上传已有的“出车检查清单.pdf”，不要编造文件内容。
员工可以从目录打开文章或文件，编辑人员可以新建文章、文件夹和上传文件。
```

![知识空间、文件夹、文章与文件上传结果](../assets/northstar-knowledge-organize-en.png)

**运输规范与司机手册形成清晰的资料目录；文章可以直接维护，已有 PDF 也能放进对应文件夹供员工查阅。**

:::tip 重要提示

维护资料需要相应的编辑权限。上传成功与文本解析完成是不同状态；需要搜索文件内容时，应确认解析已完成。资料组织和原文阅读可以独立使用，语义检索需要另行接入模型与索引。

:::
