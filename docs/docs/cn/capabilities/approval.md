# 审批

:::warning 文档编写中
本页内容正在编写。
:::

报销、请假、采购、用印、合同这类业务，核心是“谁来审、按什么顺序审、怎样算通过”。简单的提交和审批可以直接用[工作流](./workflow/index.md)完成；安装审批插件后，多级审批、会签、加签、转交、抄送等更复杂的审批规则可以更方便地搭建出来。

## 本页将覆盖

- 安装审批插件前后的区别：哪些审批不装插件也能搭建，装上后哪些审批搭建起来更方便
- 审批插件提供的能力：多级审批、按条件选择审批路线、会签与或签、按比例通过、加签、转交、退回到指定环节、抄送与阅知确认、审批时限
- 用户看到的审批界面：审批进度、审批记录、提交前的审批路线预览、并行分支的进度、审批操作栏
- 怎么装：安装插件，让 Agent 把审批接到业务单据上
- 用 Agent 定制审批流程：描述审批规则的方式和业务提示词
- 怎样调整审批流程：审批规则写在应用的代码里，不能在界面上调整；需要调整时在本地让 Agent 修改并测试，再重新部署应用
