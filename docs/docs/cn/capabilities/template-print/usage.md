# 模板打印使用说明

[← 模板打印概览](./index.md)

模板打印能力包提供面向开发 Agent 的 Skill 和参考示例，不包含现成的打印页面、渲染引擎或业务接口。生成与下载功能需要在你的应用或业务插件中实现。

## 准备模板和业务规则

| 需要提供 | 示例                                         |
| -------- | -------------------------------------------- |
| 真实模板 | 带有公司抬头、明细表格与签字区的 Word 运输单 |
| 数据来源 | 当前运输订单、客户、货物明细和签收信息       |
| 输出格式 | DOCX 下载；需要 PDF 时明确转换环境           |
| 使用范围 | 哪些岗位可以生成和下载，是否保存生成记录     |

先让 Agent 检查应用是否已有模板打印 Skill；需要接入时，由 Agent 按应用当前版本的指导安装和同步。模板、字段映射、运行依赖和业务代码都由应用维护。

## 向 Agent 描述需求

```text
根据我提供的 Word 模板，为当前运输订单生成运输单。
填充订单编号、客户、起终点和货物明细，保留模板中的公司抬头与签字区。
仅允许有权查看该订单的员工生成和下载，不接受客户端提交无权读取的订单数据。
先实现 DOCX 下载，说明缺失字段如何处理，并用真实订单验证生成结果。
如需 PDF，请先说明所需转换环境与部署依赖。
```

可以返回[模板打印概览](./index.md)选择其他场景，修改并复制提示词。

## 完成后检查

- 单条和多条明细都能正确排版，日期、金额与缺失值符合业务约定。
- 图片、二维码等内容使用可访问且获授权的数据来源。
- 生成和下载接口检查业务权限，不能通过修改订单编号读取其他人的资料。
- 输出文件能够正常打开；需要 PDF 时，在实际部署环境验证转换结果。
