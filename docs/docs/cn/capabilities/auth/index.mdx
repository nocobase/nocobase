# 认证

<p className='capability-intro'>让合适的人，以合适的方式进入应用。</p>

## 使用时需要了解什么

### 退出、禁用与重新登录

退出结束当前会话；会话过期后需要重新登录。管理员禁用账号后，应验证该账号的已有会话失效、受保护功能不能继续访问，同时保留业务记录。重新启用账号后，员工需要再次登录。

### 页面和接口一起保护

未登录用户进入内部页面时跳转到登录页；直接访问受保护接口也必须被拦截。登录身份由服务端读取，登录后的数据范围和业务操作继续由权限模块决定。

### 实际访问地址与部署配置

本地预览或部署后，认证配置需要与用户实际访问的地址一致。更换 IP、域名或应用路径时，检查 `config.yml` 中的 `app.publicOrigin` 及应用路径配置，确认服务已加载新配置，再验证登录、退出和邮件链接。详见[部署时的认证配置](./protecting-access.md#账号停用与部署)。
