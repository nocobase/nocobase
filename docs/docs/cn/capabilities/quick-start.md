# 快速启动

先启动一个 NocoBase 应用，再向 AI Agent 描述业务需求，就可以开始搭建自己的系统。本节以 Northstar Logistics 为例，用一条提示词建立客户、司机、运输订单和工作台，后续章节将在同一应用中逐步加入更多能力。

## 准备 AI Agent

准备可用的 Coding Agent、Node.js 24 或更高版本以及 pnpm 11。使用 Bash 终端安装 NocoBase 3 的全局 Skills，Windows 用户可在 WSL 中操作：

```bash
npx skills@latest add nocobase/skills-v3 --skill '*' -g
```

按提示选择你使用的 Coding Agent。安装完成后重新开启 Agent 会话，让它加载新安装的 Skills。这些 Skills 通过[轻量分发仓库](https://github.com/nocobase/skills-v3)提供，包含创建应用等指引。

应用创建后，开发用的项目 Skills 会自动同步到应用目录的 `.agents/skills/`。在应用目录开启新的会话后，Agent 使用该应用的 `AGENTS.md` 和项目 Skills 继续开发。

## 1. 创建并启动应用

在用于存放项目的目录中运行下面这条命令，从 npm 的 beta 渠道获取创建工具和默认应用模板，并安装依赖：

```bash
PNPM_CONFIG_MINIMUM_RELEASE_AGE=0 pnpm create @nocobase/app@beta northstar-logistics --template-tag=beta
```

进入新建的应用目录，初始化配置并启动。本例使用 SQLite，无需另外准备数据库服务：

```bash
cd northstar-logistics
pnpm nocobase config init --dialect sqlite
pnpm nocobase config check
pnpm dev
```

打开终端显示的应用地址，使用初始化时配置的管理员账号登录。也可以让 Agent 使用已安装的 `nocobase-create-app` Skill 帮你完成上述步骤。

## 2. 用一条提示词搭建业务

Northstar Logistics 是一家为企业客户提供区域运输与配送服务的公司。它需要管理客户、司机和运输订单，并让调度员快速找到需要安排司机的订单。

以新应用目录作为工作目录，开启 AI Agent 会话，发送下面的需求：

```text
为 Northstar Logistics 搭建运输管理应用，包含工作台、运输订单、客户、司机四个页面，使用蓝色主题和左侧导航。
工作台展示订单总数、待调度、客户数、已完成四项统计，以及订单阶段分布、待调度列表和近期订单。
订单支持搜索、阶段筛选、新建、编辑和分配司机；详情展示客户、线路、货物、负责人、费用与预计送达时间。客户和司机页面支持列表、详情及相关订单查看。
加入 10 笔订单、4 个客户和 4 名司机的英文演示数据，包含不同运输阶段，让统计、列表和详情相互关联。
```

Agent 会根据需求建立数据模型、业务页面和导航。完成后打开应用，查看搭建结果。

## 3. 查看搭建效果

### 运输工作台

工作台将订单总数、待调度数量、客户数量和已完成数量集中展示，阶段分布帮助了解整体进度，待调度列表直接呈现需要安排司机的订单。下方的近期订单可以进入详情。

示例中有 10 笔订单、4 个客户；统计和列表来自应用中的订单数据。

**订单详情展示完整业务信息，并提供编辑和分配司机入口。**

至此，应用已经具备客户、司机和订单的基础管理页面。接下来可以继续描述业务需求，在同一应用中加入登录定制、岗位权限、运输流程、审批、附件和消息等功能。

## 在同一应用中继续扩展

后续章节围绕 Northstar 的运输业务介绍各项能力。客户经理登记需求，调度员安排司机，司机执行运输并上传签收资料，运营主管监督进度，财务审核特殊运输的额外费用。

| 岗位       | 业务职责                                       |
| ---------- | ---------------------------------------------- |
| 客户经理   | 维护客户、创建运输订单、跟进交付并与客户沟通。 |
| 调度员     | 查看待调度订单、安排司机、处理运输延误。       |
| 司机       | 查看自己的运输任务、接单、出发并上传签收凭证。 |
| 运营主管   | 监督运输进度、审核特殊运输、跟进超时事项。     |
| 财务负责人 | 审核额外费用，查阅必要的财务资料。             |
| 应用管理员 | 维护人员访问规则，查看自动任务与消息投递记录。 |

认证让员工进入系统，权限决定各岗位可以查看和处理哪些订单，工作流推动运输过程，文件、通知和邮件支持日常协作。周期提醒、外部数据源、多语言和主题会在相应业务需要出现时逐步接入。

这些能力由 Agent 根据需求接入，业务页面和管理入口也可以按公司的工作方式构建。
