# 邮件

邮件能力让用户在应用中关联自己的邮箱，同步来信、阅读正文和附件，并直接写信或回复。销售沟通、客户服务、项目协作等场景可以把邮件与业务放在一起处理。

## 提供哪些能力

| 能力       | 用途                                                      |
| ---------- | --------------------------------------------------------- |
| 关联邮箱   | 通过 IMAP/SMTP 或 Gmail、Microsoft 365 授权接入个人邮箱。 |
| 同步和阅读 | 按起始日期导入邮件，在邮件中心查看列表、正文和附件。      |
| 写信和回复 | 新建邮件、回复或转发，使用附件、签名和模板。              |
| 邮件整理   | 搜索、标记已读、加星和标签；支持范围取决于接入方式。      |
| 业务结合   | 在客户、项目等页面加入邮件操作，并带入业务信息。          |

邮件中心适合处理用户与外部联系人的邮件往来。审批结果、系统提醒等自动推送消息，见[通知](../notification.md)。

## 使用邮件能力

- [邮箱接入配置](./configuration.md)：了解管理员和邮箱用户分别需要准备什么。
- [同步和发送邮件](./quick-start.md)：添加邮件中心，同步客户来信并回复。
- [更多邮件功能](./usage.md)：使用签名、模板，结合业务页面处理邮件。
- [开发参考](./development.md)：了解页面、权限和后台任务的接入方式。

IMAP/SMTP 适合收取新增邮件和发送邮件。其他客户端中的已读、删除和移动状态不会完整同步；需要更完整的邮箱整理能力时，可考虑 Gmail 或 Microsoft 365 接入。
