# 待办中心

## 1. 核心介绍

### 这些时候，用待办中心

主管需要统一查看待自己审批的请假、报销申请；员工既要补交材料，也要确认设备领取。

当需要处理的事项分散在不同业务中，就用待办中心汇集「我的待办」。

### 少找入口，更快处理

打开一个入口，就知道有哪些事等我处理，并进入对应业务办理。

减少来回切换和遗漏；办完后同步更新状态与数量，清楚掌握剩余工作。

## 2. 跟着四步，在项目中试一次

先完成 1–4 步，再按需尝试其他场景。把提示词交给应用项目中的 Agent，完成后检查结果。

### 1. 建立入口

把需要自己处理的事放在一起，不必逐个打开业务页面。

例如：主管登录后，从导航栏进入「我的待办」。

```text
主管每天要处理请假、报销等申请，希望打开应用就能在一个地方看到所有等自己处理的事情，不必逐个业务查找。
请增加一个「我的待办」页面，每个人只看到自己的事项，能区分待处理、已完成、已取消，并看到各有多少条。
```

完成后检查：

- 登录后显示自己的待办和空状态。
- 可以按业务和状态找到要处理的事项。

### 2. 接入审批

已有审批业务时，让主管在一个入口看到待自己审批的申请。

例如：同一位主管的请假和报销审批出现在同一列表。

```text
请把现有的请假和报销申请放进「我的待办」，让实际负责审批的人看到申请类型和编号，审批规则保持不变。
申请转交后由接手人处理，原审批人不再待办；申请撤回后不再要求审批。同一件事不要重复出现。
```

完成后检查：

- 转交后原接收人取消、新接收人待处理。
- 审批只展示当前允许的动作。

### 3. 完成办理

点开事项查看详情，按业务允许的动作处理，办完就刷新。

例如：主管批准一笔报销后，它进入已完成，待处理数量减少。

```text
我希望点开一条待办，就能查看申请内容并完成审批，设备领取则可以直接确认已领取。
办完后，这条事项进入已完成，剩余数量跟着变化。只允许有权处理的人操作，已撤销的事项说明原因并停止办理。
```

完成后检查：

- 只有有权处理的人能查看详情并办理。
- 办理后列表与各处数量刷新。

### 4. 验证结果

让 Agent 验证真实业务，再自己试一次。

例如：林晓处理自己的事项，陈晨看不到也不能办理林晓的事项。

```text
请用林晓和陈晨两个测试账号试一遍：各自收到事项、打开详情、完成处理，再看剩余数量是否正确。
确认两人看不到也不能处理对方的个人事项，重复点击不会出现重复工作，处理失败的事情不会显示已完成。告诉我哪些已验证，并给我一条可以自己试用的路径。
```

完成后检查：

- 两个账号的数据隔离验证通过。
- 已验证与未验证的场景分别记录。

### 设备领取

领取、补材料、确认交付，也可以成为待办，无需增加审批流程。

例如：领取单 EQ-001 发给林晓后产生待办，确认领取后完成。

```text
设备确认发放后，请让指定领取员工在「我的待办」中看到领取单，点开可以查看设备并确认已领取。
领取成功后该事项完成；管理员撤销发放后，该事项取消。同一张领取单不要重复出现，领取失败时仍保留待处理。
```

完成后检查：

- 同一件事不会重复出现在列表里。
- 领取成功后事项完成，领取失败时仍待处理。

### 首页角标

不进入完整列表，也能知道当前有多少待处理。

例如：两条报销、一条设备领取，全部待处理角标显示 3。

```text
我希望在首页一眼看到自己还有多少事没处理，点击这个数字就能打开对应的待办列表。
每办完一件事，数字和列表一起更新；没有待办时显示「暂无待处理事项」。换账号后只显示新账号自己的工作。
```

完成后检查：

- 首页数字与打开的待办列表数量一致。
- 切换业务后能找到对应事项，换账号后只看到自己的工作。

### 人员改派

原接收人的未完成事项取消，新接收人获得待办。

例如：设备领取从林晓改派给陈晨，只有陈晨还能确认领取。

```text
管理员需要把尚未领取的设备从林晓改派给陈晨。改派后，林晓不再需要领取，也不能继续确认；陈晨能看到并处理这张领取单。
已经完成的领取记录保留不变，重复改派不要产生多条相同待办。
```

完成后检查：

- 改派后原接收人不能继续办理。
- 已完成历史保留，未完成事项按规则取消。

### 历史任务

应用已在使用时，让旧任务和新任务出现在同一个入口。

例如：补齐中断后可以继续，已在线完成的事项不会重新变成待处理。

```text
应用里已经有一些没处理完的审批和设备领取，请让负责的人也能在新的「我的待办」中找到它们，并保留原来的业务记录。
整理期间新产生的工作不能遗漏，已经办完的不能再次要求处理，也不要出现重复事项。如果中途失败，下次可以继续，不必从头整理。
```

完成后检查：

- 中断后可续跑，重跑不产生重复记录。
- 已经办完的事项不会重新变成待处理。

### 业务提醒

用通知提醒「有事要处理」，实际办理仍在业务中完成。

例如：读过领取提醒但尚未领取，事项仍保持待处理。

```text
设备可以领取时，请在应用里提醒指定员工，点击提醒能打开领取单。
同一次发放只提醒一次，读过提醒不代表已经领取；只有本人确认领取成功才完成待办。提醒没送达也不影响正常领取。
```

完成后检查：

- 每次业务事件只提醒一次。
- 阅读通知不改变待办，投递失败不撤销业务。
