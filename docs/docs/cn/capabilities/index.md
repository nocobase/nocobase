# 总览

NocoBase 提供构建业务应用所需的可复用能力。你可以向 AI Agent 描述业务目标，由它接入认证、权限、数据、流程和协作功能，并构建适合业务的页面。

## 提供哪些能力

| 能力                                      | 可以解决什么问题                                                       |
| ----------------------------------------- | ---------------------------------------------------------------------- |
| [认证](./auth/index.mdx)                  | 密码或企业账号登录、管理会话、使用 API keys，并定制登录页面。          |
| [数据源](./data-sources.md)               | 选择应用数据库，接入已有外部数据库，在业务中使用相应数据。             |
| [权限](./authorization/index.md)          | 按岗位分配页面、操作和数据访问权，使用共同范围、共享、限制和权限检查。 |
| [工作流](./workflow/index.md)             | 让业务单据按环节推进，处理人工操作、外部结果、时限和办理记录。         |
| [审批](./approval/index.md)               | 接入复杂人工审批，包括多级路线、多人决策及相关协作规则。               |
| [待办中心](./task-center.md)              | 集中处理审批、设备领取等个人待办，统一查看状态和数量。                 |
| [文件](./file.md)                         | 上传、关联、预览和下载业务附件，配置存储与访问权限。                   |
| [通知](./notification.md)                 | 通过站内信、邮件或群消息发送业务结果与提醒，并查看投递记录。           |
| [邮件](./mail/index.md)                   | 关联个人邮箱，阅读和回复来信，使用签名、模板并结合业务资料。           |
| [定时任务](./scheduler.md)                | 按时间或周期自动提醒、生成报表或同步数据，查看执行记录并启停任务。     |
| [多语言](./i18n.md)                       | 切换界面语言、增加翻译并设置默认语言。                                 |
| [主题](./theme.md)                        | 调整配色、字体和布局密度，使用浅色、深色或自定义主题。                 |
| [AI 员工](./ai-employee/index.md)         | 在应用中加入 AI 协作，并接入模型、工具和业务上下文。                   |
| [AI 知识库](./ai-knowledge-base/index.md) | 管理知识资料与检索，为 AI 提供业务知识。                               |

不同能力需要的准备不同，例如外部邮箱需要服务商配置，复杂审批需要相应插件。能力页面会分别说明准备条件、业务需求和接入后的使用方式。业务页面由应用按需要构建，不要求所有管理功能都集中在统一设置页。

## 阅读本章

先查看 [快速启动](./quick-start.md)，创建应用并用一条提示词搭建 Northstar 运输工作台。随后可以沿业务过程阅读，也可以按侧栏直接查阅某项能力。
