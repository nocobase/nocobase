# 总览

NocoBase 提供认证、权限、文件、通知等可复用能力，为业务应用提供常用的基础功能。开发应用时，可以直接复用这些能力及其配套组件，减少账号管理、访问控制、消息投递等功能的重复开发，把精力放在业务页面和处理规则上。

下表列出各项能力的用途和业务场景。点击能力名称，查看具体的使用方式。

| 能力                             | 可以完成什么                                       | 业务示例                                       |
| -------------------------------- | -------------------------------------------------- | ---------------------------------------------- |
| [认证](./auth)                   | 识别当前用户，管理登录、注册和会话，扩展认证方式   | 员工登录采购系统，离职后停用账号               |
| [权限](./authorization)          | 控制页面、操作和数据的访问范围                     | 采购人员维护本人负责的供应商，主管查看团队记录 |
| [工作流](./workflow)             | 按步骤和条件处理业务，保留运行记录                 | 库存变更后检查缺口，生成补货记录并查看处理路径 |
| [定时任务](./scheduler)          | 按时间触发处理，查看下次执行时间和执行结果         | 每天检查供应商资质是否即将到期                 |
| [通知](./notification)           | 通过站内信、邮件或群机器人发送消息                 | 资质即将到期时通知负责人，并提供档案入口       |
| [邮件](./mail)                   | 关联用户邮箱，阅读、回复和发送业务邮件             | 在客户详情中处理与联系人有关的往来邮件         |
| [文件](./file)                   | 上传文件，关联业务记录，提供预览和下载             | 在供应商档案中保存资质证明                     |
| [模板打印](./template-print)     | 提供 Skill 和实现参考，帮助开发 Agent 搭建文件生成 | 按合同模板填入订单数据，生成可下载文件         |
| [多语言](./i18n)                 | 切换界面语言，添加语言，设置默认语言               | 为海外采购人员提供英文或其他语言界面           |
| [主题](./theme)                  | 调整配色、字体和布局密度，切换颜色模式             | 使用企业品牌色，或让日常操作页面更紧凑         |
| [AI 员工](./ai-employee)         | 将模型、业务工具和工作方法接入应用                 | 在客户页面查询资料、整理信息或执行获准操作     |
| [AI 知识库](./ai-knowledge-base) | 导入、处理和检索业务资料，供 AI 员工使用           | 根据采购制度回答供应商准入问题                 |
