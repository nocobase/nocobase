# 内置能力

:::warning 文档编写中
本页内容正在编写。
:::

本节介绍可复用的应用能力，以及帮助 Agent 实现业务功能的配套 Skill。每页说明解决什么问题、怎么安装、常见用法和可定制的部分；具体提供哪些现成功能，以对应页面为准。

## 本节包含

- [总览](./overview) —— 有哪些现成的能力，怎么装上。
- [认证](./auth) —— 登录、注册、会话与当前用户。
- [权限](./authorization) —— 角色，谁能看哪个菜单、哪条数据。
- [工作流](./workflow) —— 可观测、可版本化的多阶段业务过程。
- [定时任务](./scheduler) —— 代码定义、界面观测和启停的定时执行。
- [通知](./notification) —— 邮件、站内消息、飞书钉钉。
- [邮件](./mail) — 关联个人邮箱，同步、阅读和发送邮件。
- [文件](./file) —— 上传、附件。
- [模板打印](./template-print) —— 使用 Skill 引导 Agent 实现合同、订单和报表打印。
- [多语言](./i18n) —— 切换界面语言。
- [主题](./theme) —— 换配色、换字体，白天黑夜模式。
- [AI 员工和知识库](./ai-employee) —— 给你的用户用的 AI 功能。
