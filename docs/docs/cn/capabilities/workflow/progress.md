# 流程进度与处理记录

工作流可以提供当前阶段、经过的路径和处理历史。用户能知道业务走到哪里、正在等待什么，以及每一步由谁在什么时候完成、提交了哪些信息。

应用可以将这些信息做成流程图、阶段栏或记录列表，直接放在业务详情中。流程图用于展示执行进度，不是拖拽修改流程的设计器。

## 示例：查看订单交付过程

在 Northstar 订单详情中保留流程进度和每次操作的记录，便于核对签收结果和了解订单为什么进入当前阶段。

```text
在 Northstar 订单详情展示当前流程阶段和处理历史。
每条记录显示操作人、时间、操作名称、前后阶段，以及拒单原因或签收凭证。
记录系统自动执行的动作时，标明由系统执行。
刷新页面后仍保留进度和记录；完成后可以回看交付过程。
```

本例使用阶段栏和历史列表展示运输过程。[后台导出示例](./execution.md#查看执行结果)还展示系统自动执行的动作与生成结果。页面布局可按业务需要自由设计。

:::tip 重要提示

流程停滞时，先查看当前阶段、需要满足的条件和最近的处理记录；涉及外部调用时，还应查看请求是否成功、是否正在重试。修改已有流程前，需要安排未完成记录如何继续，保留已经提交的结果和历史。

:::
