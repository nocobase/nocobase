# 限制规则

限制规则让已有的岗位权限和共享遵守更具体的数据条件。例如，采购协作人员只负责金额不超过 2,000 的订单，可以用金额条件限定其可查看范围。

## 示例：只查看指定金额内的订单

```text
Alice 的采购协作职责只覆盖金额不超过 2,000 元的订单。
请为她的订单查看操作配置限制规则，只保留金额小于或等于 2,000 元的记录。
这条规则适用于她通过岗位权限、默认范围和共享获得的订单查看范围。
管理员可以在设置中选择相应的金额范围。
```

管理员在「设置 → 权限 → 限制规则」中选择 Alice、订单查看操作及金额条件。本例填写的是允许范围：金额小于或等于 2,000 元。

![为 Alice 的订单查看操作设置金额上限](./assets/restriction-rule.png)

### 查看效果

Alice 的列表保留她原本可以访问且金额符合条件的订单，包括金额为 1,550 元的共享订单 PO-2026-004。

![限制后显示金额符合条件的可访问订单](./assets/restricted-orders.png)

## 按职责设置条件

金额、业务状态等条件由应用提供。对于保密业务，也可以要求仅允许访问非保密记录。限制在已有数据范围上收窄结果，适合需要共同遵守的业务边界。

查看、编辑、审批是不同操作。需求覆盖哪些操作，应分别说明，由 Agent 接入对应规则。跨所有操作的集合限制、复杂关联条件属于进一步开发内容。
