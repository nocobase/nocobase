# 概览

从这里创建你的第一个 NocoBase 3 应用。你会先启动本地项目，再让 AI Agent 完成一个能保存数据的订单管理功能。

这里的 **AI Agent** 指能够读取项目文件、修改代码并执行命令的开发工具。后续文档统一使用这一名称。

## 适合谁阅读

如果你已经了解 NocoBase 3，准备动手体验，可以从这一部分开始。你需要能在终端运行命令、用编辑器打开项目，并在浏览器中检查结果；不必先掌握插件开发。

有开发经验的读者可以直接进入[创建应用](./create-app)。如果你还在了解产品，建议先看[NocoBase 3 是什么](./index)，了解产品定位和适用场景。

## 完成后你会得到什么

- 一个保存在自己目录中的应用项目，包含页面、服务端接口和数据库迁移。
- 一个可以登录的本地应用。
- 一个订单列表，支持新增和修改订单，刷新后数据仍然保留。
- 一次完整的 AI Agent 协作体验：说明需求、查看改动、操作检查、反馈修正。

这里先完成小功能。客户关联、业务员权限、主管审批和通知会在后面的订单教程中逐步加入。

## 开始前准备

| 准备项            | 用途                                             |
| ----------------- | ------------------------------------------------ |
| Node.js 和 pnpm   | 创建项目、安装依赖、运行应用；具体要求见创建应用 |
| 编辑器和 AI Agent | 打开应用目录，让 AI Agent 读取并修改项目文件     |
| 终端              | 执行创建、启动和检查命令                         |
| 浏览器            | 登录应用，操作页面，确认结果                     |

AI Agent 需要事先完成自己的账号和模型访问配置。首次体验使用 SQLite，不需要先安装独立数据库服务。

## 阅读顺序

你可以选择[AI Agent 创建应用](./create-app)，也可以按[手动创建应用](./create-app-manually)在终端操作。两种方式完成后，都继续到第一个功能。

| 步骤                                        | 要解决的问题                     | 完成标志                           |
| ------------------------------------------- | -------------------------------- | ---------------------------------- |
| [创建应用](./create-app)                    | 项目建在哪里，怎样运行？         | 浏览器可以打开应用并登录           |
| [让 AI Agent 做第一个功能](./first-feature) | 怎样交给 AI Agent 一个具体需求？ | 订单可以保存、修改，刷新后仍然存在 |

按顺序完成即可。项目创建一次后，后面的改动都在这个项目中继续，不需要每做一个功能就重新初始化应用。

跑通第一个功能后，「和 AI Agent 协作」的几页帮助你把需求说清楚、检查结果，并推进更大的功能。想跟着一个案例把数据、页面、权限和流程接起来，阅读[订单系统教程](../tutorials/)。
