# NocoBase 3 是什么

**让软件跟上业务的想象力。**

NocoBase 3 是面向 AI Agent 开发的企业业务系统底座。它将应用源码、通用能力和开发指引结合起来，让你和 AI Agent 在已有基础上构建自己的系统，把开发投入集中到真正创造业务价值的地方。

**我们的目标，是让各类业务系统都能基于 NocoBase 3 构建、改造和持续演进。** 从一个部门的管理工具，到跨部门协作的复杂系统；从全新的业务想法，到多年积累的既有系统，我们希望为它们提供共同的开发基础，让业务经验更直接地转化为软件能力。

## 为什么选择 NocoBase 3

### 通用能力复用，业务价值持续积累

认证、权限、通知等通用能力，可以成为不同业务模块共享的基础。你在这个基础上构建客户、订单、项目和流程，让每一次开发都成为下一次扩展的起点。系统越完善，团队能够复用的业务成果就越丰富。

### 让 AI Agent 成为业务系统的建设者

AI Agent 能够读取项目、修改代码和执行命令。NocoBase 为它提供应用结构、开发约定和能力指引，让需求可以落实到相互配合的页面、接口和数据模型。你提出业务目标，与 AI Agent 一起把它推进成完整功能，并在使用中持续改进。

### 掌握源码，定义系统的未来

应用源码保存在你的项目中。页面如何呈现、规则如何执行、功能如何扩展，都可以由团队继续开发。你可以管理版本、部署应用，也可以让开发者与 AI Agent 接力协作，让系统沿着自己的业务方向发展。

## 从业务构想到持续演进的系统

你带来业务知识，AI Agent 将需求落实为代码，NocoBase 提供可复用的基础能力。这三者结合，让“提出需求、实现功能、使用反馈、继续迭代”成为同一个项目中的持续过程。

![你和团队描述需求并检查结果，AI Agent 修改代码形成业务应用；NocoBase 为开发提供指引，为应用提供通用能力。](https://static-docs.nocobase.com/nb3-docs-20260916-intro-collaboration-cn.png)

## 你想构建怎样的系统

**把你希望实现的业务系统，作为想象的起点。** 下面是这套开发底座希望承载的应用方向：

| 业务方向           | 可以围绕哪些目标展开设计                               |
| ------------------ | ------------------------------------------------------ |
| 客户与经营管理     | 串联客户、商机、合同和订单，形成完整的经营过程         |
| 企业运营与资源管理 | 围绕采购、库存、资产等业务，组织跨部门的数据和流程     |
| 项目与组织协作     | 连接项目、任务、资源和审批，让团队围绕共同目标工作     |
| 行业专属系统       | 按照行业规则设计数据、界面和业务过程，形成自己的应用   |
| 既有系统改造       | 从需要改变的模块切入，规划业务重构与系统对接，逐步演进 |

订单教程展示了其中一条具体路径：从订单录入，到角色权限、主管审批和结果通知，逐步把业务组织成一个系统。

![订单系统中的详情页，展示订单信息和业务操作。](https://static-docs.nocobase.com/nb3-docs-20260916-tutorial-detail.png)

从这个例子出发，你可以继续构想自己的业务模块、协作方式和系统全貌。
