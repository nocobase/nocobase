# Studio

Studio 将项目、任务和 Agent 协作集中在一个工作区。你可以描述业务需求，让 Agent 整理任务，再交给开发 Agent 完成应用开发。本节以运输订单管理应用为例，介绍从登录到创建第一个项目的过程。

## 选择你的使用方式

| 你想做什么                                           | 使用方式                               | 需要准备什么                                   |
| ---------------------------------------------------- | -------------------------------------- | ---------------------------------------------- |
| 在 Studio 网页与在线项目助理对话，整理需求、查询任务 | 添加模型服务                           | 模型服务的 API 地址、API Key 和可用模型        |
| 在本地 Codex 等 Agent 中操作 Studio，创建项目和任务  | 在你的 Agent 中使用 Studio             | 已可用的本地 Agent；安装 Studio CLI 并确认登录 |
| 在 Studio 网页下发任务，由本地 Codex 等 Agent 执行   | 添加运行环境，选择 Runner 类型的 Agent | 在目标电脑安装并登录编码工具，再接入 Runner    |

- **Studio CLI**：Studio 的命令行工具，供本地 Agent 查询和管理项目、任务等工作区内容。通过“在你的 Agent 中使用 Studio”入口安装，并使用 Studio 账号授权登录。
- **Runner**：运行在电脑、服务器或虚拟机上的任务执行服务，接收 Studio 下发的任务并调用本机编码工具。通过“添加运行环境”入口接入。
