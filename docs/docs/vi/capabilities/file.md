# Tệp

Tải lên, xem trước và tải xuống các tệp gắn với bản ghi, với quyền nghiệp vụ kiểm soát việc truy cập.

Chọn một kịch bản trong trang tổng quan và điều chỉnh prompt cho phù hợp với ứng dụng của bạn. Xem [hướng dẫn sử dụng](./file/usage.md) để biết chi tiết.
