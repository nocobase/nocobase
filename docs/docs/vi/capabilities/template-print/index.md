# In theo mẫu

Cung cấp một mẫu nghiệp vụ và yêu cầu Agent triển khai việc tạo và tải xuống chứng từ. Gói này cung cấp Skill và ví dụ; ứng dụng sở hữu phần triển khai khi chạy.

Đọc [hướng dẫn sử dụng](./usage.md) để biết yêu cầu về chuẩn bị mẫu, phân quyền và chuyển đổi sang PDF.
