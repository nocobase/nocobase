# Ngôn ngữ

Thêm bản dịch cho giao diện và server, cấu hình ngôn ngữ mặc định và giữ lựa chọn ngôn ngữ của từng người.

Chọn một kịch bản trong trang tổng quan và điều chỉnh prompt cho phù hợp với ứng dụng của bạn. Xem [hướng dẫn sử dụng](./i18n/usage.md) để biết chi tiết.
