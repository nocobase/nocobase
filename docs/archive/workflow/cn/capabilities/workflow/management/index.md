# 工作流管理

本部分面向业务管理员。管理界面用于管理应用开发者已经发布的工作流，不提供流程结构的创建或修改能力。

## 可以进行的操作

- 查看工作流列表、详情、流程图和历史版本
- 设置开发者开放的管理员参数
- 启用、停用或启用新版本
- 在授权场景下手动运行指定版本
- 查看运行状态、实际路径、节点结果、错误和日志

## 操作边界

管理页面中的流程图是只读的。节点、分支、输入格式和参数声明都来自应用开发者发布的源码，管理员不能在界面中增加、删除或连接节点。

启停、参数修改和手动运行都会改变应用状态，其中手动运行还可能产生真实业务副作用。操作前应确认目标版本和影响范围。执行历史是诊断证据，不应通过删除或改写历史来掩盖失败。

当前管理页面和相关 API 要求用户已登录，并通过工作流页面的访问检查。应用部署者仍应按组织要求限制谁可以进入管理区域；不要把登录本身理解为细粒度的操作审计。

## 给应用开发者的反馈

发现异常时，不要只反馈“工作流失败”。提供工作流名称、运行 ID、版本、触发时间、整体状态、第一个失败节点以及错误或日志是否被截断，开发者才能基于实际执行版本定位问题。
