The UI Library catalog describes the `permission-editor` with up to three tabs: Menus, which only decide which business menus a role sees in the sidebar; Business objects, where each object's actions and View scope are set once and other actions follow or narrow it; and System settings, where each settings page's actions are set without data scopes. It also installs `permission-editor-model.ts`.
