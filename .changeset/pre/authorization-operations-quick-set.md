Operations in the role editor are a table of every object, grouped: each row checks View with its data scope and the object's other operations directly, a data scope opens from a tag beside its operation, and a checkbox per object, per group or for everything turns on every operation except high-risk ones, or turns them all off. On phones each object becomes a card with the same checkboxes.
