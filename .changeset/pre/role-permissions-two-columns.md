Roles and permissions set a role in three tabs. Menus choose which business menus the role sees in the sidebar and are stored as page access on their own; Business objects set each object's actions and data scope once for every menu that uses it, with other actions following or narrowing View and scopes titled by their registered collections; System settings set each settings page's actions without data scopes, and a settings page shows in the sidebar once the action that opens it is on. Actions that can grant permissions carry a warning, the system administrator is shown as unrestricted, a role can be duplicated, and switching roles asks before discarding unsaved changes.
