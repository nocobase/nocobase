Preinstall plugins with their Skills, unregister them while retaining the development dependency, and use plugin remove for a complete uninstall. Create apps from Professional and Enterprise template packages by alias. Default preinstalls Web Push and its Skill for opt-in registration. Default also preinstalls PostgreSQL, MySQL, SQL Server and Oracle drivers for opt-in deployment and keeps SQLite as its runtime default.
