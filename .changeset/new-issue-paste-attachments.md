Keep screenshots pasted into a new issue's description. The New issue form uploads files pasted or dropped on the description, or chosen with its "Attach files" button, lists them below it with an image thumbnail, an upload spinner and a remove button, and sends them as the new issue's own files. The form cannot be submitted while a file is still uploading, keeps the files after a failed create, and discards them when it is left without creating, except while a create request is on its way, which may already have attached them. A paste that also carries plain text, such as cells copied from a spreadsheet, is still pasted as text.

`POST /api/projects/issues` and the plan operation `issue.create` take `attachmentIds`, the caller's uploads attached to nothing, and attach them to the new issue in the same transaction, recorded as `attachment_added`. Sending them needs `upload` on `pm.attachments`; an id that is not such an upload fails the request with `INVALID_ATTACHMENT` and creates nothing. `issue create` on the command line takes `--attach <file>`. `POST /api/projects/attachments/discard` deletes those of the caller's uploads still attached to nothing and leaves the rest alone. `useAttachmentUploads` takes `discardOnUnmount`, which discards through that route, and `setSending`, and `PmRichTextEditor` takes `onFiles` for pasted and dropped files.
