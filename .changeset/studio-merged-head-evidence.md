Tell runners which issue working directories may go, for old directories too: a directory named only by its issue key resolves to that issue while Studio still has it, and the runner is shown, as proof its commits were pushed, the head each merged pull request was merged at, under the URL the project checks the repository out from only when its host and full repository path match the identity recorded with the confirmed head. Equivalent HTTPS and Git SSH URLs are accepted; editing a checkout URL to another host or repository removes its evidence. Studio records that head only from what GitHub confirmed — a verified merge delivery, a read of the merged pull request, or the head Studio's own merge named — never from a person's "mark merged", a fork's head or the squash commit, and stops offering it when two confirmations disagree. Pull requests recorded merged before this release get theirs while repositories are polled, ten per repository per poll. The `202610230010_studio_pull_request_merged_heads` migration adds the columns; existing rows start without a head.
