Add `@nocobase/app-plugin-agent-sessions`: conversations in the browser with the coding agents on people's own computers, connected with `<cli> acp start`. Each session is its owner's alone and keeps its full transcript in the application, redacted of secrets. A new session starts from the model, reasoning effort, speed, mode and commands the agent offered on that computer, in a folder chosen by browsing the computer rather than typing a path, and may work for one of the application's projects (`registerProjects`); messages sent while the agent works wait their turn, and the owner answers the agent's permission requests and changes its choices from the page. Applications tie their own records to sessions with `registerLinkKind` on `agentSessionsToken`, so a session shows how they stand, its owner starts their work in one step and mentions them in a message with `#`, and the agent knows them as the session's tasks: each message tells it what changed since the last one, and `list_session_work` tells how each is going; tell the agents how to work with `registerInstructions`; and give the agents their tools as an MCP server over HTTP at `/mcp/agent-sessions` with `registerTools` and `defineSessionTool`. The page `/agent-sessions` lists the sessions with their records, filters for those waiting for the owner and by project, archives them with one key, and works on a phone.
