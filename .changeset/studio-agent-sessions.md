Add My agents: talk in Studio with Codex or OpenCode running on your own computer, connected with `nb-studio acp start`. The agent works with full access in the folder you choose by browsing your computer, for the project you choose, and creates and finds Studio issues through Studio's tools, in that project unless you name another; mention an issue in a message with `#`. The issues a session creates wait in backlog and show in the conversation, where you start the ones you keep in one step, and in the session list with their project and status.
