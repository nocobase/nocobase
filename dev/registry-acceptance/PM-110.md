# Public registry acceptance in a workspace plugin

Acceptance on 2026-10-09 did **not** pass the complete build-and-run path. Public `shadcn add` installed a component into a manually generated workspace plugin, and its package-local imports worked in a running Default application. The plugin declaration build failed because upstream Base UI primitives lacked explicit exported types. Before declaring Base UI as a peer, the generated plugin also could not resolve that dependency. No import alias was added or rewritten.

## Environment and scope

- Source revision: `c7c14b2742c24f4e8c910e0381254f690605c6b2`.
- Node `24.21.0`, pnpm `11.7.0`, shadcn `4.18.0`, TypeScript `6.0.3`.
- React `19.2.8`, Base UI `1.7.0`, cn `0.4.0`, lucide-react `0.487.0`.
- Host: the complete `packages/templates/app-template-default` application, using its own local SQLite storage, backend, browser runtime, plugin composition and theme.
- Plugin: `packages/plugins/app-plugin-pm110-registry-acceptance`, created by a direct workspace CLI command, outside the automated create-plugin test fixtures.
- Browser: Playwright-driven Chromium `151.0.7922.34`. These were actual browser pointer clicks, with synthetic state; no person performed the clicks.
- The temporary acceptance route used `auth: 'optional'` and `authz: 'skip'`. It rendered in the application's standalone page layout, without signing in or exercising the authenticated sidebar.

## Browser evidence

At `http://127.0.0.1:14110/main/pm110-registry-acceptance`, Chromium rendered the plugin's component and exercised:

1. Initial state: `enabled=true`, `level=own`, `changes=0`.
2. Pointer click to switch off: `enabled=false`, `changes=1`.
3. Pointer click to switch on and choose “All records”: `enabled=true`, `level=all`, `changes=3`.
4. Collapse and expand the section, asserting the switch was hidden and then visible.
5. Reload the direct plugin URL and verify initial local state again.
6. Capture the same page at 1280px and 375px widths.

The first browser run completed those actions but recorded React invalid-hook-call console errors. A second fresh browser run after dependency optimization settled, from `05:32:32.455Z` to `05:32:34.935Z`, completed the same actions with zero console errors, page errors or failed requests. This establishes a clean later development run; it does not erase the first run's errors or prove their root cause. The issue includes both records and screenshots. The development processes were then stopped.

The import audit verified unchanged `components.json`, `tsconfig.json`, `imports` and `publishConfig.imports`; all four installed files had no `@/` import. Default's Vite configuration was untouched. The build errors concern missing dependency/types, while browser development successfully resolved the package-local imports.

## Other checks and limits

The temporary plugin's lint reported 47 quote-style errors in untouched upstream primitive source. Its generated scaffold test suite had one passing component test and one failing “starts without an invented route” test, because the acceptance harness deliberately added a route. That scaffold assertion was not a component-runtime regression, and was not rewritten to make the report green.

This was a development-source browser check, not a run of a successful production build or an installed tarball. Authentication, authorization APIs, saved permissions, real business data, other registry items, Examples, dark mode, alternate theme presets and deployment were not verified. The dependency install was online, but it used this monorepo's workspace packages and shared dependency store; it was not a fresh standalone application installation from published NocoBase packages.

The remaining product work is to supply the Base UI dependency for this generated-plugin workflow and decide how public upstream primitives receive plugin-compatible declaration types. Re-run both plugin and full-application builds before claiming the complete acceptance path passes. The public registry may change; use the captured source files to reproduce this historical failure.
