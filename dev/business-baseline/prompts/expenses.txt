Build expense reimbursement in this clean Default application. Employees choose a permitted active project and create reimbursement claims with expense lines. Projects can be inactive or restricted to certain employees. Each line has a description, a positive integer quantity and a nonnegative two-decimal unit amount. Use CNY only. Each claim belongs to its employee and has one designated supervisor who is a different person. Users need usable business pages and the existing user/role administration to manage explicit assignments. Reuse existing execution history for decisions; do not add a separate workflow management page.

Employees can save incomplete drafts, search/filter projects and claims, and add, edit or remove expenses. Display line amounts and the total. The server must calculate and validate amounts, reject forged totals, invalid quantities, excessive precision and unsafe totals. Save the claim and all expenses atomically. A failure after an earlier expense write must leave no partial new claim and must preserve all previous values of an existing claim.

Use draft, submitted, rejected and approved states. Employees edit only their own draft/rejected claims. Submission requires a valid project and at least one valid expense. Only the designated supervisor approves or rejects a submitted claim, never their own claim. After rejection the employee corrects and resubmits; approved claims cannot change. Repeated or concurrent submit/decision calls produce only one state change and history effect. Stale edits cannot overwrite decisions.

Enforce all permissions on the server for lists, details, expenses, project candidates and all writes/actions, even through direct requests. Employees see only their own claims and supervisors see only assigned work. Other employees, other supervisors, unassigned signed-in users and anonymous users cannot read or alter protected records. Recheck project scope on writes and prevent foreign expense IDs or forged employee, supervisor and state. Buttons must follow these rules. Include repeatable synthetic data, automated browser and server tests, and installation, startup, test and isolated-data reset instructions.
