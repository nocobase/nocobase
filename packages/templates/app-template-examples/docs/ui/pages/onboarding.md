# Employee onboarding page design

The structure reference is the existing Examples procurement list and the customer detail child page. Retain native navigation, DataTable pagination, inline error feedback and theme tokens. New and existing cases open as a covering `RouteChildPage` with `BackButton` and `PageHeader`, so the form has the whole content area. The approved interaction is a local four-step form with explicit draft saves; switching steps makes no request. There is no external visual reference or page-specific theme.

| Element        | Composition                                                                                          | Acceptance                                                                                                                                                                                                                                                                                                                                                                          |
| -------------- | ---------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| List           | PageContainer, PageHeader, DataTable, Input and local shadcn Select                                  | Search by name/email and filter status; show loading, empty and retryable read errors. New is visible only to coordinators.                                                                                                                                                                                                                                                         |
| Wizard         | RouteChildPage, Card, FeedbackForm, one controlled input object, a step list and a sticky action bar | From `lg`, a vertical step list marks done/current/upcoming/attention and reopens completed steps; below it, "Step n of 4" and a progress bar. Next validates only the current step and lists linked problems. Previous retains values. The first incomplete step is derived on reopen, with a restored notice. One primary action; Save draft is secondary beside the saved state. |
| Employment     | Position and Contract field sets, department Select, employment type ToggleGroup, Inputs             | Full-time probation and contractor end date are required as appropriate. Department selection uses authorized candidates.                                                                                                                                                                                                                                                           |
| Documents      | Required-document StatusBadges and rows of Select/Input with an icon remove button                   | Badges name each required document and its reason. Rows form a table from `md` and stack below it. Each document has type, title and reference number. Missing conditional documents prevent confirmation. No upload UI.                                                                                                                                                            |
| Confirmation   | Read-only definition lists grouped by step with Edit actions, and a document Table                   | Echo all entered values. Save before submit. Submitted view includes employee ID and authorized history.                                                                                                                                                                                                                                                                            |
| Write feedback | Native submission controller, inline error and explicit reload                                       | Disable both write actions through detail refresh; retain original key after uncertain results and retain input on conflicts.                                                                                                                                                                                                                                                       |

At 1440×1000 the step list sits beside a two-column form card; at 390×844 fields and confirmation values stack, document rows become cards and the action bar stays pinned with full-width buttons. Neither the child page nor the document scrolls sideways. Use semantic colors in light/dark and both density presets. English/Chinese copy comes from the page locale module. A coordinator and HR viewer have independent capabilities; draft detail remains private even to another coordinator or administrator. Use the scoped case view for history instead of registering confidential drafts in the example's unrestricted workflow inspection catalogue.
