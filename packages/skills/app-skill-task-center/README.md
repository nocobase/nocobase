# @nocobase/app-skill-task-center

Public installation and integration guidance for `@nocobase/app-plugin-task-center`. This package contains documentation only and does not install or license the commercial runtime.

Install this package as a development dependency in a NocoBase application, then run `pnpm nocobase skills sync` with an App CLI that supports standalone Skill packages. On older CLIs, read the [Skill](skills/nocobase-app-plugin-task-center/SKILL.md) directly.

Start with [installation and version selection](skills/nocobase-app-plugin-task-center/references/installation.md), then follow the [integration Skill](skills/nocobase-app-plugin-task-center/SKILL.md). The `nocobase.skill` manifest entry records the inspected runtime version and source revision; it is provenance, not an installation dependency or an automatically enforced compatibility range.
